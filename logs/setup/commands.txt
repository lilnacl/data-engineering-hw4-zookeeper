Все команды выполнялись из папки ДЗ4. Для CLI внутри контейнера использован клиентский порт 2181.

docker compose config --quiet
docker compose config
docker compose up -d --wait --wait-timeout 120
docker compose ps --format json
docker compose exec -T zk1 zkServer.sh status
docker compose exec -T zk2 zkServer.sh status
docker compose exec -T zk3 zkServer.sh status
docker compose exec -T zk1 java -version
docker compose exec -T zk1 zkServer.sh version
docker compose exec -T zk1 cat /conf/zoo.cfg /data/myid
docker compose exec -T zk2 cat /conf/zoo.cfg /data/myid
docker compose exec -T zk3 cat /conf/zoo.cfg /data/myid

Интерактивная проверка:
docker compose exec -T zk1 zkCli.sh -server zk1:2181
create /hw4-setup-smoke ready
get /hw4-setup-smoke
delete /hw4-setup-smoke
stat /hw4-setup-smoke
quit
Ожидаемый exit code 1: stat обращается к уже удалённому узлу.

printf 'create /hw4-setup-smoke ready\nget /hw4-setup-smoke\ndelete /hw4-setup-smoke\nls /\nquit\n' | docker compose exec -T zk1 zkCli.sh -server zk1:2181
