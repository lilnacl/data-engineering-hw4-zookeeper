# Скриншоты терминала

Сохранила пять кадров с просмотром журналов выполненных опытов. Для ролей серверов использовала cat, для кворума и эфемерного узла — grep. В двух опытах координаторов показала выбранные поля A.log, B.log и summary.json через scripts/terminal_evidence.py.

Кадры 01–03 относятся к logs/ensemble/20261105T092042Z/. Кадр 04 — к logs/failover/20261105T095054Z-without-fencing/, кадр 05 — к logs/failover/20261105T095153Z-with-fencing/.

ConnectionLoss после потери кворума, Node does not exist после завершения сессии и BadVersionError при устаревшей эпохе — ожидаемые результаты этих проверок.
